# 图灵判别盲测（强校验）

这是比「单篇相似度判官」更狠的一关。相似度判官问「像不像」；图灵判官问「**这是真迹还是 AI 仿的**」——把 AI 仿写混进真迹里，让一个崭新的、**不同模型**的判官盲猜。判官正确率越接近 50%（瞎猜）= 仿得越像。

> 什么时候上这一关：用户想验证「指纹卡到底硬不硬」、想要可量化的过/不过、或要拿卡去给别的模型批量用之前。普通改写一篇用 `judge-prompt.md` 那套相似度判官就够。

## 致命的设计陷阱（踩过的坑，必须避开）

1. **别给写手太多信息**。给「事实骨架 / 多句要点」让 AI 改写 → AI 基本是在**复述原文**，等于作弊，判官分不出是因为内容几乎一样，不是因为文风像。
   → 正确：每篇只给 **标题 + ≤30 字中心思想**，让全新写手 agent **从零写整篇**，例子/人名/结构全自己造。这才真考文风。
2. **「人类」那一组必须是纯手写真迹**。别拿已经被 AI 润色过的稿子当真迹基准——人/AI 界限本就糊了，测了白测。对王建硕：用 2006–2013 **博客时代手写随笔**（`home.wangjianshuo.com/content/cn/*.md`），不要用 2026 公众号（已过 AI 润色）。
3. **必须剥光元信息 + 统一格式**，否则判官靠格式取胜（测试无效）：
   - 去掉署名行 / 标签 / 评论数 / YAML frontmatter / 文末链接块；
   - 抹平 markdown（`[文字](url)`→文字、去 `**`、去 `>` 引用、去 `#` 标题符、去图片 `![]()`）；
   - **段间空行统一**（全部折叠成单换行或全部留空行——两组要一致；AI 默认 markdown 双换行、真迹常单换行，这是头号格式破绽）。
4. **判官要异模型 + 崭新 + 盲 + 一次读整批**。作者用 Opus 写，判官就用 Sonnet（或反过来）。把 12 篇全文**嵌进 prompt**，别让它读文件（防止偷看密钥 KEY.json）。给它 1–2 篇确凿真迹做校准参考会让测试更严。

## 操作步骤

1. **选样**：随机取 N 篇真迹。一半留作「人类组」（原文展示），一半抽出**标题 + ≤30 字中心思想**当「AI 组」种子。两组**选题尽量同原型**（都叙事 / 都观察报道 / 都技术），否则判官靠「文章原型」就能分（见 ai-tells.md 第 6 条）。平衡：6 真 + 6 AI 是好起点。
2. **生成**：每个种子起一个**全新写手 subagent**，只喂「风格卡 + 标题 + 30 字」，**严禁读原文**。6 篇要**各用不同的签名动作/收尾**，绝不批量同款（见 ai-tells.md 第 5 条）。
3. **组装**：12 篇全部走第「致命陷阱 3」的归一化，打乱编号，密钥另存 `KEY.json`（判官看不到）。
4. **判官**：崭新异模型 subagent，prompt 里嵌入：1–2 篇校准真迹 + 12 篇待测全文 + 「这些都署名某作者，有真迹有 AI 仿写，逐篇判真迹/AI，必须全判、不许弃权、留意是否有几篇共享同一套路（批次指纹）」。
5. **算分**：正确率 = 判对数 / 12。**≤ 50% 算过**。同时看 **AI 召回**（6 篇 AI 被抓几篇）——召回越低越好。
6. **回炉**：不过标，拿判官的**具体出戏理由**改那几篇被抓的（换说法、换收尾、补硬锚点、消批次同款），再换一个崭新判官重测。最多几轮。

## 诚实的能力天花板（9 轮实测结论，写给用户别画大饼）

- 平衡盘里，判官对**真迹的召回近 100%**（真迹满是无法伪造的具体噪音：真实价格/人名/当场改错的旁注/跨篇人物）。于是正确率**地板就是 50%**——要更低，得让 AI 好到**反过来诬陷真迹**，极难。所以「稳定压到 50% 以下」基本做不到，别承诺。
- **但单篇经常能蒙混**：纯记叙/观察/报道/清单型的 AI 仿写，常 4/6 骗过很毒的判官。**一旦想"升华点题"、落一句可迁移金句，立刻被抓**。
- 结论传达给用户：**指纹卡的主场是「润色/改写作者已有真实素材」**（锚点真、原型他自己定，单篇足以乱真），不是「凭空批量伪造一整本文集骗鉴定专家」。

## 部署：写进作者的 jianshuo.dev profile（可选收尾）

VoiceDrop 那套挖文章管线按「每用户文风」生成文章，文风存在用户名下的 `CLAUDE.md`（结构：`# 我的名字\n<名>\n\n# 我的文风\n<style-card 正文>`）。更新方法（**token 由用户当场提供，绝不写进 skill / 不进 repo**）：

```bash
# 先 list 确认名下有 CLAUDE.md，并下载备份旧版
curl -s -H "Authorization: Bearer $TOK" https://jianshuo.dev/files/api/list
curl -s -H "Authorization: Bearer $TOK" https://jianshuo.dev/files/api/download/CLAUDE.md -o profile.bak
# 组装 名字头 + 我的文风 + style-card，PUT 覆盖，再下载逐字节校验
curl -s -X PUT -H "Authorization: Bearer $TOK" --data-binary @new_CLAUDE.md \
  https://jianshuo.dev/files/api/upload/CLAUDE.md
```
upload 后**重新 download 比对一致**才算成功。
