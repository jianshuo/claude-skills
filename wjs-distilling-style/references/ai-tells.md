# AI 仿写最易露馅的 6 处（9 轮图灵盲测逼出来的）

判官几乎只盯这 6 点。每堵上一层，判官就退到下一层——所以这是个递进清单，从最低级（好堵）到最高级（最难堵）。把对应的反制写进每张风格卡。

1. **缺真实专名（头号死穴，最好堵）**
   AI 怕杜撰，退成泛指：「朋友」「一家公司」「那本书」「有一年」。真迹满是真实人名/地名/日期/价格/书名。
   → 反制：专名一个都不许泛化。从零生成时，写手要自己造**可信的具体专名**（街道、航班号、人名、价格）；改写时原素材里的真专名原样保留。

2. **结尾收得太圆**
   诗意对仗金句 + 首尾 callback（结尾回收开头那个物件）+ 行动号召（「加油 / 群里报名」）。
   → 反制：结尾要钝、要散。禁对仗诗意句、禁 callback、禁口号。宁可挂一条「注 / PS」软着陆，或抛个开放反问，或干脆停在一个不漂亮的地方。

3. **推进太顺、无岔路**
   观察 → 三层展开 → 闭环，干净得可疑。
   → 反制：故意留毛边——中途离题、补个括号、挂条限定的「注」、留一处真没想通的地方。

4. **鸡汤化 / 教科书化**
   把一个观察打包成可迁移方法论（三步走 / 三要素 / N 个技巧），再用「薯片 / 手机 / 读书 / 早睡」这类放之四海的通用例子填充。读起来像行为设计自助文。
   → 反制：别替读者总结「方法」。例子扎进某个具体领域的真实细节（某次具体的会、办公室真实家具），不要通用生活例子。允许「没有中心思想」的篇——只记一件事，不升华。

5. **批次指纹（一批一起测时最坑）**
   判官一次读多篇。一批 AI 若共享同一招牌动作——同样的「写到这儿我卡住了」式崩裂、同样的「注：」收尾节奏、同样的「我懂道理但做不到」自我拆台——判官立刻认出「同一只手」，一锅端。**注意：判官会把"动作"抽象到很高层**，你换了表层措辞，它还能认出底层套路（如「自我拆台」这个 move 本身）。
   → 反制：每篇的签名动作/崩裂/收尾必须**换花样**；宁可有的篇根本不用某个动作，也别全批同款。

6. **文章原型不匹配（最高层，最难堵）**
   AI 爱写「私人场景 → 推导出一个关于人性的哲理命题 → 用反例打薄它 → 『人本如此』式闭环」这种**反思落点型**散文。可真迹更多是**观察 / 报道 / 技术 / 游记 / 流水账型**，不落人性大道理、结尾开放、话题跳接、拿不为论点服务的旁注收场。一批 AI 全是反思落点型，摆进一堆观察报道型真迹里，结构上一眼鹤立鸡群。
   → 反制：(a) 多写观察/报道/技术/记叙型，少写每篇都要顿悟人性的；(b) **盲测时让 AI 组和真迹组同原型**（见 turing-blindtest.md）；(c) 终极铁律——**有没有落一句"可单独流通的金句/论点"是判官最爱抓的**。要嘛只记事不点题（让结尾散掉），要嘛认了那一两篇会被抓。

> 一句话：AI 失之于「太干净、太像在教你、一批长一个样、篇篇都要顿悟」。真迹是「从一件具体事里长出来、带毛边、钉死真实专名、长到哪算哪、常常压根不升华、钝钝地散开而不是合上，每篇脾气还都不一样」。
