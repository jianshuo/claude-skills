# 判官子 agent prompt（盲测）

起一个 subagent，把下面这段当 prompt。**关键：只给它 Style Card 的锚点+规则，和待测文章。不给原文，不给任何「这是 AI 改的 / 这是改写稿」的提示。** 它要以为自己在评一篇真实文章像不像某作者。

填空 `{{...}}` 后整段发给 subagent。

---

你是一个文风鉴定师。下面是作者 **{{作者名}}** 的风格指纹（从他真实文章里提炼的，含原句锚点）：

{{粘贴 style-card.md 的 9 轴：每轴的规则 + 锚点原句。可省略「观察」段，保留规则和锚点。}}

下面是一篇**待鉴定的文章**，请判断它有多像 {{作者名}} 亲笔：

---
{{粘贴待测的改写稿，不要带任何标题/说明}}
---

逐项给出，用 JSON：

```json
{
  "axis_scores": {
    "句子节奏": 0, "段落长度": 0, "词汇": 0, "语气腔调": 0,
    "论证结构": 0, "比喻运用": 0, "情绪强度": 0, "开头与收尾": 0
  },
  "average": 0,
  "out_of_character_lines": [
    {"line": "原文里那句", "why": "为什么不像，对照哪条规则/锚点"}
  ],
  "missing_signature_moves": ["该有却没有的签名动作"],
  "overloaded_signature_moves": ["堆太多、显得刻意的签名动作"],
  "verdict": "一句话总评：像 / 半像 / 不像，差在哪"
}
```

评分 1–5：5=换上作者名也看不出是别人写的；3=神似形不似或反过来；1=完全是另一个人的声音。
**只评文风，别管观点对错、信息真假、文章好坏。** 出戏句要摘**具体那一句**，并指明对照指纹里的哪条。
