# 踩坑表（两本 20 分钟书实测，一条一个修法）

| 现象 | 原因 | 修法 |
|---|---|---|
| 整片渲染、两本同时渲，后台进程被杀 | 16GB Mac 内存压力，Claude Code 回收后台 shell | `render_chunks.py` 按章一进程、可续跑；同时最多 2 个渲染进程；一次只渲一本 |
| qa 跑到两百镜左右停住，log 空、没有 qa.md | Playwright 驱动偶发 EPIPE（位置不固定），stdout 缓冲没落盘 | `qa_batches.py` 每批 70 镜一进程、失败重试、`PYTHONUNBUFFERED=1`；长任务用 `nohup … &` 脱离会话 |
| 字幕比声音晚半秒，念数字的句子错几秒 | 用了 TTS 自带的字级时间戳：停顿后的句首晚 0.5–1s（实测 16–18% 的句子差 >0.3s），对齐脚本还不认「9,999 / 九千九百九十九」 | `narrate.mjs` 一律火山 ASR ＋ difflib 式按字对齐（对不上的字前后插值） |
| ASR 报 `Invalid audio format … fail to feed audio into decoder` | 多段合成的 mp3 每段都带 ID3 头，夹在文件中间 | 只保留音频帧再存、再推（`mp3Frames`） |
| 想把动画口播写进听书缓存省一次钱 | 两份不是同一段话时会把「听本章」换成别的内容 | 口播只用听书那一份；从不往 `audiobook/` 写，缓存只由听书接口自己写回 |
| 成片被截短 | ffmpeg `-shortest` 按短的那条截 | assemble 在音轨尾部补静音帧到段落表总长 |
| 推近后画面边上半个字、半个物，持续 2–3 秒 | 长镜头（6–8s）把推近终态停住；推近中心只对着画面一侧 | 推近中心取所有要读物的中点；qa「半截字」逐条看 `framing_sheet.py` 两帧对比 |
| 开场头两秒物体在画外 | 「从两侧滑入」的初始状态放在画外，又被 lt 偏移拉长停住 | 初始状态放画内边缘；复用旧镜头加 lt 偏移时先看第 0 秒那帧 |
| 画面出现方框/豆腐块 | 字体是 GB2312 子集，⁶⁰ ½ − ¢ 繁体都没有 | 上标手画；`U.assertGlyphs` 报错就换写法 |
| HTML 版中文乱码 | Artifact 页面没有 meta charset，外部 js 按 latin-1 读 | 所有 `<script>` 带 `charset="utf-8"`；本地用 `_test.html` 测 |
| HTML 版 `SCENES is not defined` | 场景文件比引擎先执行 | 模板里先 `window.SCENE_LIBS=[]; window.SCENES={}` 再引场景 |
| HTML 版字体不生效 | 浏览器按网址懒加载字体，首帧画完才到 | fetch 成 ArrayBuffer → `new FontFace` → `document.fonts.add`，字体就绪后才插 engine.js |
| `Path2D.ellipse` 把几段连成一笔 | 子路径没 moveTo | 每个椭圆单独一个 Path2D 再 `addPath` |
| popText 传进去的透明度不生效 | 函数内部覆盖了 globalAlpha | 乘上传入值，不覆盖 |
| zsh 循环传多个参数只传进去一个 | zsh 不按空格拆词 | `${=var}` |
| 连续世界后几镜被加了转场 | `window.SEAMLESS` 加载太晚 | shots.json 第四列 `"seamless"`，assemble 读 |
| 最后一章片尾被截 | 每章强制 = 音频＋GAP | 只有最后一章允许更长（片名停留） |
| 章间太赶 | GAP 0.4s | `book.json` `gap: 0.8` |
| 字幕一闪而过、空字幕底框、数字被拆两行 | 短句直出 | assemble：≤17 字合并、>18 字拆、数字量词不拆、<0.8s 并或延、空条不出 |
| 门禁黄灯「最长无事件间隔」「最差 30 秒窗口」 | 有意的一镜到底长镜头、沉下来的段落 | 不必改；在交付说明里写时间码和理由 |
