# 《{{TITLE}}》· 章节制作规范（给每位章节制作者）

你负责全片里一两章的动画画面。全片 = ch01–ch{{N}}，口播就是书架听书的整章朗读（一章常有 4–8 分钟），每章单独计时；你只管自己那几章的「章内局部时间」（0 = 本章口播第一个字）。总装、字幕、整片渲染、HTML 打包由总导演做，你不碰。

## 1. 先读这些（必读）

- `~/.claude/skills/huashu-art-motion/SKILL.md` 的「导演的要求」两节和「六种做坏方式」、`references/镜头语言.md` 第一到四节、`references/动画语法/` 里本片语法（{{GRAMMAR}}）的「起手必查」。
- 本片画风套件（**只读，不许改**）：`代码工程/scenes/book/lib.js`，导出 `K`。现成接口：{{API}}。先通读一遍。本书专属道具在 `scenes/book/props.js`（总导演维护）。
- 你那几章：口播文本 `稿/chNN.txt`（ASR 从听书音频识别出来的，就是观众听到的话）；句时间 `音频/chNN.句时间.txt`（`开始-结束  短句`，秒，章内局部时间，可直接拿来定切点）；音频 `音频/chNN.mp3`。

## 2. 画风锁（全片一致，不许偏）

- 画风：{{KIT_LABEL}}。所有形状、文字、底都走套件函数，不自己发明新画法。
- 只用色板：{{PALETTE}}（套件里是 `K.C`）。**禁止**蓝紫、渐变底、霓虹外发光、换画风拼贴。
- 贯穿物：按 `稿/README.md` 写的本书主物，每章至少一两镜让它在场。
- 人：不画脸、不画 Q 版小人；人群用 ISOTYPE 图标或剪影，只出手。动物只画剪影。
- 文字：只用套件的 text / popText / callout。**只用 GB2312 里有的字**：繁体、上标（⁶⁰）、½、−、¢ 这类没有，上标手画。手机竖屏最小字号 44px，标签 52px 以上，大标题 100–170px。

## 3. 竖屏版式（1080×1920，视频号 9:16）

- 主体放在 y 200–1350；**y 1380–1560 是字幕带，不放任何字和关键图形**；y > 1574 是视频号底栏遮挡区。
- 每镜结尾调 `K.finish(c)`；屏上大字每镜 ≤ 8 字，整句话交给字幕。
- **长镜头里推近，推近中心要让画面里所有要读的物都留在可见宽度内**（1.25 倍时可见宽 864px：中心 x 必须让最左、最右的物都在 ±432 内）。镜头停在推近后的状态超过 1 秒，切边就会被看见。
- **开场初始状态也要全在画内**：物从两侧滑进来的，第一帧就停在画内边缘，不要从画外开始停几秒。

## 4. 镜头与节奏

- 一镜 2–6 秒（个别 6–8 秒，绝不超过 8 秒）；每句口播至少一次状态变化（弹出、形变、钻入、拉远）。
- 镜头：`CAM.track(base, events, lt)` + `K.world(c, cam, fn)`。缓推/横移/拉远是过渡；快推、砸入是重音，只给揭晓、反转、关键数字，每章 ≤ 3 次。推进去要有来有回，不连着三镜往里推；相邻两镜换构图。
- **禁止**「顶部大字＋居中图标＋淡出」一镜接一镜的 PPT 模板。多用：同一世界里横移到下一件、从细节拉远看全貌、物的形变、连续世界拆成两三镜（用 `K.t0('<那组第一镜 id>')` 拿起点，按全片时间 t 驱动，shots.json 第四列写 `"seamless"`）。
- 开场 3 秒是具体的小场景；每章结尾落在一个物的动作上。所有随机用 `U.hash`/`U.rng` 种子。
- 示意性的数字、图表，画面上标「示意」。口播里说过头的事实画面上别加强，拿不准的回报给总导演。

## 5. 你要交的东西

1. `代码工程/scenes/book/chNN.js`：镜头 id 一律 `cNN_<名字>`，注册 `SCENES.cNN_xxx = { draw(c, lt, t) { … } }`；IIFE 包住，开头 `const D = K, C = D.C, { W, H, TAU } = D, { clamp, lerp } = U;`。新道具挂 `D.cNN_xxx`，不改 lib.js / props.js。
   - 第一镜必须是章节卡：`SCENES.cNN_card = { draw(c, lt, t) { D.chapterCard(c, lt, t, N, D.CHAPTER_NAMES[N - 1]); } };`，时长 = 念章名那一句＋0.3 秒左右（听书每章开头会念「第 N 章＋章名」）。
2. `音频/chNN.shots.json`：`[[id, 局部开始, 局部结束(, "seamless")], …]`，首镜从 0 开始、首尾相接、最后一镜结束 = 本段音频时长＋0.4 秒；切点放在句首前 0–0.15 秒。
3. `代码工程/eras_chNN.js`（自测片子，模板见下）和 `镜头表/chNN.md`（huashu-art-motion `references/镜头表模板.md` 的表格）。
4. 自查：冒烟检查零报错、零缺字；框景线索逐条确认（能看静帧的机器上，每个新镜头渲中段、末段两张静帧全部过目）；回报每章镜头数、平均镜长、你觉得最弱的 3 镜和原因。
