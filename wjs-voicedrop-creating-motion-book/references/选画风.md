# 自动选画风（按书的内容，在全部可选风格里挑一个）

画风由 AI 定，不停下来问用户；选型结果图发给用户看，用户说换才换（否决权在人）。

## 1. 读书，写内容画像（5 行）

读全书目录和每章开头两段，写进 `稿/README.md` 顶部：
- 题材（医学/金融/历史/自然/技术/人文…）
- 讲法：机制系统？事件史？清单步骤？数据走势？个人经历？
- 数据密度：有没有大量会被较真的数字、图表
- 情绪：冷静科普 / 制度庄重 / 温暖 / 紧张
- 贯穿物候选：一个能从开场到结尾反复出现、能「变形」进每章的具体物（药片的胶囊、美联储的 25 美分硬币）

## 2. 先定语法，再定画风

语法按 huashu-art-motion `references/09-视频动画语法.md` 第二节「怎么为一段口播选语法」：一本书讲机制 → y1 Kurzgesagt 或 t1 3b1b；讲事件史、有原话截图 → y2 Vox；数据为主 → t3 财经图表，可叠在主语法上。

## 3. 候选池与初筛（3 个候选）

候选池 = 本 skill `kits/*/kit.json`（已有套件，看 `fits` / `avoid`）＋ huashu-art-motion `references/风格配方/INDEX.md` 里质量 ★★★ 的材料层风格＋上一步语法自带的画法。

初筛成 3 个**互相差得开**的候选，规则：
- 有 `fits` 命中本书题材的已有套件，必须进候选（复用套件省掉 1–2 小时的建库和试错）。
- 研究配方（未到 ★★★）不进候选。
- 三个候选要分别代表不同取向：最对题的、最清楚的、最能撑满 12 章的。

## 4. 每个候选出一张主镜头

挑全书最核心的一句话（最能代表全书机制的那句），三个候选画**同一句**、同一时刻，竖屏 1080×1920，放 `三方向/<候选名>/t003.00.png`。已有套件直接用套件函数写；新画风写一个最小原型。三张拼成 `三方向/三方向对比.jpg`。

## 5. 独立评委打分

派一个**没参与画图**的子 agent，只给它三张图、内容画像和下面的表，让它逐项打分写理由，结果写 `三方向/评审.md`：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 信息清晰 | ×1.5 | 3 秒内看懂这一镜讲什么 |
| 题材贴合 | ×1 | 一眼是这个题材，不是任何题材都能套 |
| 能撑满全书 | ×1.5 | 12 章里叙事章、数据章、人物章都画得出来，20 分钟不看腻 |
| 辨识度与审美 | ×1 | 有作者性，不像模板 |
| 没有 AI 味 | ×1 | 无蓝紫渐变、霓虹、Q 版小人、拼贴换风格 |
| 竖屏手机可读 | ×1 | 主体占画面一半以上，字够大，视频号压缩后细线不糊 |
| 制作风险（高分=低风险） | ×1 | 全片统一的难度；已有套件这项高 |

加权满分 80，取最高分。**前两名差距 ≤ 2 分时选已有套件那一个**（时间省一大截，质量已被一整本书验证过）。选中后把胜出方向与另外两个的对比、理由、全片用法（色板、贯穿物怎么进每章）写在评审结论里，拼一张 `三方向/选型结果.jpg` 发给用户。

## 6. 选中的是新画风：先做成套件再开工

在本 skill 的 `kits/<名字>/` 建 `lib.js` + `kit.json`，下一本书就能直接用。`lib.js` 必须实现「套件接口」：

| 接口 | 作用 |
|---|---|
| `window.K = { W, H, TAU }`、`K.C` | 导出名固定为 K；色板 |
| `K.at(lt,a,d)`、`K.pop(lt,a,d)`、`K.once(k,f)`、`K.t0(id)` | 进度、弹出、缓存、连续世界起点（按 ERAS 读，不写死秒数） |
| `K.round`、`K.circle`、`K.world(c,cam,fn)` | 路径与相机 |
| `K.bg(c,t,o)`、`K.text`、`K.popText`、`K.callout`、`K.finish(c)` | 底、字、引线标签、每镜收尾（字幕带压暗） |
| `K.CHAPTER_NAMES = (window.BOOK_META||{}).chapters` | 章名来自 book.json，不写死 |
| `K.chapterCard(c,lt,t,n,title)` | 章节卡，N 站进度按章数算 |
| `K.subtitle(c,text,alpha)` | 字幕样式（字幕带 y≈1480） |

`kit.json` 写 `name / label / grammar / fits / avoid / fonts / palette / api`。字体只能放开源许可的进 skill；系统自带字体（如 macOS 宋体）写成 `{"ttc", "index"}`，由 new_book.py 在本机抽子集——**本 skill 会同步到公开仓库，商业字体文件不能进来**。
